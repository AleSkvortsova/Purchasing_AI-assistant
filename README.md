# ИИ-ассистент по внутренним заявкам на закупку

Telegram-бот «Закупкин» превращает свободное описание товара или услуги в
структурированную внутреннюю заявку. Он извлекает уже указанные сведения,
задаёт последовательные уточнения, сохраняет черновик и регистрирует карточку
только после явного подтверждения пользователя. Отдельный режим отвечает на
вопросы по учебным внутренним регламентам с указанием источников.

MVP развернут на VPS и принят с известными ограничениями. Он готов к
демонстрации на проверенных сценариях, но не заявляется как промышленная
система закупок.

## Проблема и решение

Внутренние заявки часто поступают в свободной форме. Заказчик не всегда знает
категорию, обязательные поля и маршрут согласования, поэтому закупщик вынужден
возвращаться за количеством, характеристиками, сроком, бюджетом и целью.

Ассистент стандартизирует первичное описание и сохраняет подтверждённую
потребность в едином реестре. Языковая модель помогает понять текст и
сформулировать справочный ответ, но обязательность полей, конфликты, категории,
числовые диапазоны, жизненный цикл и регистрация контролируются программным
кодом и PostgreSQL.

## Основные возможности

- оформление заявки на товар или услугу в Telegram;
- OpenAI Structured Outputs с детерминированной нормализацией и fallback;
- категории G01–G15 и S01–S15, выбор из сохранённых кандидатов;
- разделение подтверждённых сценариев разных категорий;
- один восстанавливаемый активный черновик пользователя;
- карточка, изменение свободным текстом, отмена и явное подтверждение;
- номер `PR-YYYY-NNNNNN` и статус «Передана в отдел закупок» (`new`);
- пять последних заявок владельца в read-only режиме;
- Regulation Q&A с гибридным поиском, источниками, многошаговыми уточнениями и
  контролируемым отказом;
- предварительный маршрут согласования по структурированным правилам;
- FastAPI API и Swagger для технических операций.

## Ключевые границы

В MVP нет фактического согласования, кабинета закупщика, проверки бюджета,
выбора поставщика, актуальных цен, ERP/1С/WMS-интеграций, вложений и SSO.
Карточка рассчитана на один основной предмет и не заменяет полноценную
построчную спецификацию. Полный scope и план/факт зафиксированы в
[`FINAL_TECHNICAL_SPECIFICATION.md`](docs/final/FINAL_TECHNICAL_SPECIFICATION.md),
следующие этапы — в [`PRODUCT_BACKLOG.md`](docs/planning/PRODUCT_BACKLOG.md).

## Архитектура

```text
Telegram / aiogram long polling
  → adapter
  → Structured Outputs + программный разбор
  → объединение, проверка полноты и категории
  → persistence orchestration
  → Supabase RPC / PostgreSQL
  → confirm, edit или cancel
```

```text
Вопрос по регламенту
  → understanding и slots
  → semantic + Russian full-text retrieval
  → RRF
  → ответ по выбранным фрагментам
  → проверка утверждений, значений и источников
```

Telegram-адаптер вызывает внутренние сервисы напрямую; FastAPI не является
промежуточным слоем для бота. Инженерные детали приведены в
[`TECHNICAL_ARCHITECTURE.md`](docs/technical/TECHNICAL_ARCHITECTURE.md).

Основной пользовательский поток начинается кнопкой «Новая заявка». Бот
извлекает сведения из первого сообщения, задаёт по одному следующему вопросу и
при необходимости показывает 2–4 категории. После заполнения обязательных
полей пользователь видит карточку. Только кнопка «Подтвердить и отправить»
регистрирует заявку; свободный текст на экране проверки этого не делает.
«Текущая заявка» восстанавливает черновик, «Мои заявки» открывает краткую
историю, а «Спросить по регламенту» запускает изолированный справочный режим.

## Стек

- Python 3.11–3.12, aiogram 3, FastAPI и Uvicorn;
- Pydantic и pydantic-settings;
- OpenAI Responses API, Structured Outputs и `text-embedding-3-small`;
- Supabase PostgreSQL, pgvector/HNSW и Russian full-text search;
- pytest, Ruff, Git и GitHub;
- VPS, Python virtual environment и systemd.

## Быстрый локальный запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

Создайте `.env` на основе `.env.example`, задайте серверные ключи и запустите:

```powershell
uvicorn app.main:app --reload
python -m app.bot
```

FastAPI будет доступен на `http://127.0.0.1:8000`, Swagger — на
`http://127.0.0.1:8000/docs`. `.env` и секреты нельзя коммитить или передавать
клиенту. Миграции `001`–`009` применяются вручную; приложение не выполняет их
автоматически. Полный runbook находится в
[`ADMIN_GUIDE.md`](docs/operations/ADMIN_GUIDE.md).

Основные каталоги репозитория: `app/` содержит приложение, `knowledge_base/` —
14 учебных источников, `data/evaluation/` — фиксированные наборы,
`scripts/` — CLI и подготовку данных, `scripts/sql/` — миграции, `tests/` —
автоматические проверки, а `docs/` — документацию по аудиториям.
